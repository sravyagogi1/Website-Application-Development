Flask Problems Setup

1. Each problem is in its own folder.
2. Open a terminal in the problem folder you want.
3. Run: python app.py
4. Open the route for that problem in your browser.

- problem1: /
- problem2: /home
- problem3: /dogs
- problem4: /
- problem5: /home
- problem6: /home
- problem7: /
